# Đêm Rằm — Trung Thu 3D

Trang Trung Thu 3D (Three.js): đảo nổi với cây đa treo đèn lồng Hội An, thỏ ngọc, đèn kéo quân, cá chép bay, mặt hồ phản chiếu, và đèn trời xếp thành chữ "Châm ♥".

- Xem online: https://namht4devlop.github.io/trung-thu-3d/
- Chạy trên máy: mở `index.html` (hoặc `python3 -m http.server` rồi vào http://localhost:8000).

## Nhạc

Bài hát không có trong repo vì có bản quyền. Trang phát theo thứ tự:

1. File mp3 chọn bằng nút 🎵+ (trình duyệt nhớ cho lần sau)
2. `nhac.js` đặt cạnh `index.html` (chỉ có trên máy, đã bị `.gitignore`)
3. Bản piano tự tạo bằng Web Audio
